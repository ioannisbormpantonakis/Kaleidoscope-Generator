# Kaleigen v1.0.2



## DESCRIPTION



The goal of this project is to create an application (kaleidoscope.exe)
which generates kaleidoscopes from a given set of images. For each image,
**8 different kaleidoscopes** are generated, out of which:

- **4** use Horizontal or Vertical symmetries (one of these)
- **4** use Horizontal and Vertical symmetries (both of these)


## DOWNLOAD

You can download the standalone executable file (`kaleidoscope.exe`) from the **[Releases](https://github.com/ioannisbormpantonakis/Kaleidoscope-Generator/releases)** section. No Python installation is required.


## HOW-TO-USE



1. Create a folder named `input_data` in the same folder as the application.
	
2. Paste your images into the `input_data` folder. 

3. Run `kaleidoscope.exe`. A terminal window will open showing progress.

4. An `output_data` folder will be created containing the generated kaleidoscopes.

**Enjoy!**
